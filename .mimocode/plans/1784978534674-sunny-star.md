# Color Scheme Update: Black & White Theme

## Goal
Convert the entire portfolio from the current stone-based dark theme to a clean black & white palette with white backgrounds. Buttons and select CTAs can use accent colors (rose, green, etc.) for emphasis.

---

## Color Mapping

### Backgrounds
| Current (Dark) | New |
|---|---|
| `bg-stone-900` / `dark:bg-gray-950` | `bg-white` |
| `bg-stone-800` / `dark:bg-stone-800` | `bg-white` |
| `bg-stone-100` / `dark:bg-stone-800` (cards) | `bg-white` border `border-gray-200` |
| `bg-stone-200` / `dark:bg-stone-700` (inputs/tags) | `bg-gray-100` |
| `bg-stone-700` / `dark:bg-stone-700` (hover states) | `bg-gray-100` |

### Text
| Current | New |
|---|---|
| `text-stone-100` (headings light) | `text-black` |
| `text-stone-900` (headings dark card) | `text-black` |
| `text-stone-500` / `text-stone-600` (body) | `text-gray-600` |
| `text-stone-400` (subtle text) | `text-gray-400` |
| `text-stone-300` (card body dark mode) | `text-gray-700` |
| `text-white` | `text-white` (on dark buttons only) |

### Borders
| Current | New |
|---|---|
| `border-stone-200` / `dark:border-stone-700` | `border-gray-200` |
| `border-stone-300` / `dark:border-stone-600` | `border-gray-300` |
| `border-stone-400/30` (tape strips) | `border-gray-300` |

### Buttons (Accent Colors Kept)
| Element | Color |
|---|---|
| Primary CTA ("View My Work", "Hire Me", "Send Message") | `bg-black text-white` |
| Secondary CTA ("Let's Connect", "Contact") | `border-2 border-black text-black` hover `bg-black text-white` |
| "Book a Call" | `bg-rose-800 text-white` (keep rose accent) |
| "Open to Work" badge | `bg-green-600 text-white` (keep green) |
| Social icons | `text-gray-500 hover:text-black` |
| Active nav item | `bg-gray-100 text-black` |
| Theme toggle | Keep but default to light |

### Decorative Elements
| Element | Update |
|---|---|
| Tape strips on flyer cards | `bg-gray-200` |
| Pushpins | Keep rose/slate colors as subtle accent |
| Grain texture overlay | Remove or make very subtle `opacity-[0.03]` |
| Animated stickers (AI, ML, etc.) | `bg-gray-800 text-white` |
| Typing animation text | `text-black` |

## Key Rules
- NO dark backgrounds on main sections (everything white)
- Cards = white bg + thin gray border + subtle shadow
- Headings = black
- Body text = gray-600
- Buttons = black (primary) or border-black (secondary)
- Rose/green accents ONLY on: "Book a Call", "Open to Work" badge, pushpin decorations
- Remove `dark:` variants OR override them to match light theme
- Tape strips on flyer cards → `bg-gray-200` (light, subtle)
