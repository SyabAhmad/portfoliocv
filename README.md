# Sara Ali — Portfolio

A modern, expressive portfolio for Sara Ali — UI/UX Designer & Developer, and the vision behind MenteE. Features a "pinned flyer" aesthetic with the Caveat handwriting font, rotated card transforms, scattered sticker tags, and smooth Framer Motion animations.

## Tech Stack

- React 19
- Vite 7
- Tailwind CSS 4
- Framer Motion
- Lucide Icons
